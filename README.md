# Vehicle Rental Management System 🚗

A Python-based Vehicle Rental Management System that allows users to manage vehicles, rent vehicles, track availability, and calculate rental charges.

## Features

- View available vehicles
- Search vehicles by type
- Rent a vehicle
- Store customer details
- Calculate rental charges
- Track vehicle availability
- View active rentals
- Return vehicles
- Generate rental details
- Input validation

## Technologies

- Python
- Dictionaries
- Lists
- Functions
- Loops
- Conditional Statements
- Exception Handling

## How to Run

python vehicle_rental.py

## Concepts Used

- Dictionary
- List
- Functions
- Loops
- Conditional statements
- Input validation
- Exception handling
- Mathematical calculations
- Data management

## Purpose

This project helps practice Python data structures, functions, input validation, vehicle tracking, rental management, and billing logic.
